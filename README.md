# NyanEngine

A custom C++ Game Engine built from scratch, inspired by [The Cherno's Game Engine Series](https://www.youtube.com/playlist?list=PLlrATfBNZ98dudnM48yfGUldqGD0S4FFb) (Hazel) and [Harold Serrano](https://www.haroldserrano.com/).

---

## Prerequisites

Make sure you have the following installed and added to your system `PATH`:
* **C++ Compiler:** MinGW-w64 (GCC with C++17 support or newer)
* **Make Utility:** `mingw32-make` (included with MinGW)
* **Build Configuration Tool:** Premake5 (bundled in `vendor/bin/premake/premake5.exe`)
